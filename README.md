Leonida Legend — an offline guide and tracker for all 55 PlayStation 5 trophies of Grand Theft Auto VI: official names, descriptions and grades, a cited guide for each trophy, a roadmap to the platinum with the one possibly missable trophy flagged, and a checklist that saves in your browser.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 — or serve `app/` with any static file server. It works with the network off: every file it loads lives in `app/`.
